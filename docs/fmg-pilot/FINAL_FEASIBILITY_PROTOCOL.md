# Final feasibility protocol — frozen before generation, October 29, 2026

One bounded experiment; no production changes, sales, purchases, customer messages or database mutations. Existing fictional CRA/CTM input file is unchanged. Historical v0.3 reports and generic baselines remain archived in the prior results.

Six stages: deterministic exact JD extraction; deterministic candidate evidence extraction; direct HTTPS employer-source inspection; explicit clinical competency rules; one ID-only recommendation ranking call; separate claim validation against original input and inspected source passages. The model cannot create factual prose. Unknown independent-monitoring duration and qualifying CTM tenure remain unknown. Role-duration sums do not prove qualifying or non-overlapping experience. Mandatory/preferred classifications retain their source wording. Rules are professional interpretation, not employer acceptance decisions.

The ranking model is the existing free-credit `openai/gpt-5-mini` profile. Fetch live model metadata and prices before calling it. At most four generation calls, no retry: CRA ranking, CRA strong generic baseline, CTM ranking, CTM strong generic baseline. Local conservative reservations must remain under $0.50 additional credits. Existing OIDC identity; no key creation or paid fallback. Each generic baseline uses the unchanged strong `baselinePrompt`, identical raw CV/JD and the same freshly inspected employer-source packet. Same model, low reasoning, 4,500 maximum output tokens. Specialized ranking adds explicit clinical rules. This compares a constrained rule pipeline against generic synthesis, not proprietary research or the entire ChatGPT product. Old baseline scores remain historical; fresh baselines avoid unequal source access.

Deterministic/adversarial tests must pass before any generation. Each live packet is compiled and independently validated with a deterministic registered selection before its ranking call. After ranking, validate actual output fields again. Record generation IDs and reconcile actual cost using read-only Gateway endpoints. No automatic regeneration or speculative prompt tuning after seeing results.

Diagnostic rubric (each dimension 0–5): employer specificity/relevant verified sources 20%; factual accuracy and epistemic calibration 25%; candidate personalization 20%; clinical competency reasoning 15%; actionable recommendations 15%; clarity/usability 5%. Score = sum(weight × rating / 5). Same rubric for all four outputs. Record specific evidence for each rating. Review by Codex is unblinded AI review, not independent human SME validation, buyer approval or a statistical study.

Meaningful advantage is predeclared as specialized score at least 80/100 and at least 10 points above its strong generic comparator for BOTH cases. Safety gate: zero material unsupported candidate or employer claims, exact supplied requirements, correct arithmetic, verified relevant sources, practical personalized actions, AND independent human clinical-review checkpoints. An automatic pass or AI reviewer does not satisfy the human gate. No automated-product GO without that gate. One case per product cannot establish general reliability.

Human checkpoints: original-input claim audit; CRC/CRA/CTM scope and duration; mandatory/preferred fidelity; employer-source relevance and limitations; application/interview usefulness and safe disclosure; final customer-ready approval. Reviewer name, date and explicit attestation must be recorded by an actual human. Missing review remains pending.

Decisions: GO only if all gates complete; CONDITIONAL GO only for a clearly bounded next step with outstanding conditions explicit; NO-GO for automated sale if safety/differentiation fails. If this bounded experiment cannot justify automation, stop automated report investment and recommend a founder-reviewed concierge validation pilot, subject to human review and launch approval. Do not silently relabel concierge delivery as a validated automated product.
